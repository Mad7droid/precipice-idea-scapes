# Release 0.1.7 — 11 October 2026

Scapi requests use basic web search, avoiding the implicit code-execution records introduced
by dynamic search. Search fallback and malformed-history recovery handle plain streaming
error payloads and retain bounded retries. A failed request after partial output is not
restarted into the same answer. Billing, permissions, oversized requests and provider outages
have specific safe messages.

This release also includes idle Scapi click reactions, a brief mascot failure cue, and MCP
guidance to show `preview_flow` when users ask to see a flow, journey or wireframes.

Targets: production Pages and Workers, and the macOS application. No new infrastructure,
database migration or dependency is required. The macOS build is ad-hoc signed, without
Developer ID signing or notarization. App data and Keychain service identifiers are unchanged.

Validation: 739 frontend/Worker tests pass and the production build passes. Stream recovery
tests cover unavailable search, malformed history, bounded retries and partial output.
The exact provider rejection shown in the reported screenshot has not been reproduced with
a live user credential.
