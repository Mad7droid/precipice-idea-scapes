# Release 0.1.8 — 11 October 2026

Scapi recognizes Anthropic's API usage cap and displays a safe reset timestamp when supplied.
Previously this rejection appeared as a generic HTTP 400. Billing-credit failures and
temporary rate limits retain separate messages. The SDK's default raw-error logger is
suppressed so request content does not appear in the console.

A minimal fictional request reproduced the reported HTTP 400: Anthropic said the account's
specified API usage limits had been reached. The app cannot override that account limit;
the account owner must adjust it in Anthropic Console or wait for the reset. No private canvas
content was used for the diagnostic request.

No infrastructure, migration or dependency changes are required. macOS artifacts remain
ad-hoc signed, without Developer ID signing or notarization.
