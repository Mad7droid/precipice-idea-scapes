# Precipice 0.1.14

Released 2026-10-22 (`5a15672`, lockfile fix `34f87d5`). Reconstructed from the CHANGELOG
entry and git history after the fact; no separate release notes were written at the time.

## Jev-only routing

- Settings → AI gains **Use Jev only**. Jev routes alone with up to 4 s to answer and no
  on-device fallback. When Jev cannot answer, the reason is shown (for example a rejected
  key or no answer in time) and live voice does not run that phrase.

## Live voice context

- Softened requests such as "can you just simplify this?" route as edits, both on-device and
  in Jev's rubric. Simplify/shorten/merge/clean-up edits change or remove existing objects
  instead of adding new ones.
- Spoken requests reach the model marked as speech, with the last three phrases and what the
  previous run changed, so "it" and "that" keep their meaning. Spoken questions get short
  answers.
- `docs/jev-architecture-review.md` records the routing architecture review.

## Verification

The release commit records no verification log. Known gap found later: the native Jev
request timeout was 2 s while the UI allowed 4 s, so slow Jev answers in the Mac app failed
early. Fixed in a later release by raising the native timeout to 4 s.
