# Release 0.1.12 — 22 October 2026

Live voice, dictation on the web, and clear "who is working" labels.

- **Live voice.** Press Live in the Scapi composer and talk. Each finished phrase is routed
  (on-device, or TypeSafe Jev when enabled) and runs as an Ask, Edit, Connect or local
  command, with no Send. Phrases run one at a time in spoken order; routing for the next
  phrase starts while the current one runs. Each phrase shows its decider, model, routing
  time and run time. Every edit remains a single undoable transaction; Ask cannot write.
- **Web dictation.** The browser's on-device Web Speech recognition (`processLocally`), with
  live interim text and listening that continues across pauses. No cloud recogniser is used;
  unsupported browsers show dictation as unavailable. Chrome currently offers English and
  Hindi on-device; Malayalam remains Mac-only.
- **Indicators.** The routing pill names its decider (`Jev`, Jev in progress, `auto`, or
  `local` after a Jev timeout). The Ribbon and Scapi answers show `Claude · <model>` or
  `ChatGPT · <model>`.

Infrastructure: `Permissions-Policy` changes from `microphone=()` to `microphone=(self)`.
No new dependency or migration. macOS artifacts remain ad-hoc signed, without notarization.

Verification: `pnpm verify`, `pnpm test:mcp`, `cargo test`, desktop build with signature
check. In real Chrome 155, the language pack installed and Live started and stopped. Live
use with real speech has not been run by a person yet.
