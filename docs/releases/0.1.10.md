# Release 0.1.10 — 21 October 2026

A memory and storage cleanup for long-running sessions, most noticeable in the macOS app,
which tends to stay open for days.

- Undo keeps the most recent 200 steps per open scape. Each step holds the values it
  replaced, so an unbounded stack grew for as long as a scape stayed open. A simulated session
  of 20,000 text edits retained 87 MB before and 1.1 MB after.
- The edit-history log trims itself on a session's first write as well as every 200 writes.
  The trim deletes by key instead of loading every row. Previously a scape that only saw short
  sessions was never trimmed.
- MCP receipts are removed at launch once they are 30 days past expiry. `get_history` and
  `revert_operation` cover that window. Previews that are still publicly shared keep their
  receipt so they can always be withdrawn.
- The publication projection and its SHA-256 are only computed for scapes with a live
  publication, instead of on every edit of every scape.
- Scapi holds only the turns it sends back to the model.

Shared by web and macOS. No new dependency, infrastructure or database migration. macOS
artifacts remain ad-hoc signed, without notarization. `pnpm verify`, `pnpm test:mcp`,
`cargo test` and the desktop build pass.
