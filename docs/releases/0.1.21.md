# Precipice 0.1.21

## Scape version history

- Automatic local checkpoints and named milestones preserve earlier scape versions.
- Open History (More → Version history on a phone) to explore a saved version directly
  on the canvas, compare changes with current work, and inspect complete before/after blocks.
- Restoring requires confirmation and preserves the replaced work in a safety checkpoint.
  The restoration is one undo step and survives restart.
- AI and connected-agent edits participate in history. Camera-only movements do not create
  versions. History stays in the current browser or Mac library and is excluded from exports.
- Existing libraries upgrade in place; history begins from their saved state. Versions from
  before history was enabled cannot be recovered retroactively.

## Home

Home leads with Scapi and the composer for both new and returning users. A compact continuation
link replaces the large returning-user card. Duplicate home actions remain in the sidebar.

## Verification

- Production build, worker types, version checks, and 1,043 web tests passed.
- Seven MCP transport tests and 49 native tests passed; three native tests remain ignored.
- Desktop and phone browser flows verified preview isolation, comparisons, confirmed restore,
  and recovery after reload using isolated fictional content, with no browser console errors.
- A macOS app bundle passed its build and signature checks before packaging this release.

## Distribution and limits

The Apple Silicon desktop image uses the project's existing ad-hoc signing configuration;
it is not Developer ID signed or notarized. Updating the installed app retains its bundle
identifier, local library, and Keychain service. There is no automatic in-app updater.
Physical-phone gestures and on-screen keyboard behavior remain unverified on hardware.

See [version history](../version-history.md) and [desktop installation](../desktop.md).
