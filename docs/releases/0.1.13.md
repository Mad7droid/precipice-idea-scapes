# Release 0.1.13 — 22 October 2026

Fixes from the first real use of live voice in the Mac app.

- **Jev in the Mac app.** TypeSafe's CORS policy rejects the app's `tauri://localhost` origin,
  so every desktop Jev request failed and routing fell back to on-device. A restricted native
  command, `jev_route`, now makes the request. It reads the key from Keychain and reuses a
  pooled HTTPS connection; the webview sends only the bounded routing body.
- **Compact live voice.** Live adds no height: the composer's text row becomes one live line,
  the Live button becomes Stop with a timer, and history opens as an overlay. The progress
  strip is one row while working, and the canvas answer card is capped at 28vh.
- **One sentence, one request.** Phrases settle for 600 ms, and speech heard in that window
  joins them. Stale Jev answers for a superseded phrase are ignored.
- **Canvas answers** render markdown and object chips like the Scapi panel.
- Errored live runs show as failed. The Send button no longer wraps, and the fallback label
  no longer claims a timeout.

No new dependency or migration. macOS artifacts remain ad-hoc signed, without notarization.
Verification: `pnpm verify`, `pnpm test:mcp`, `cargo test`, desktop build with signature
check, and a headless Chrome check of the live UI with a scripted recogniser.
