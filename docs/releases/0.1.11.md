# Release 0.1.11 — 22 October 2026

Voice, routing and the first subscription connection.

- **Dictation (macOS app).** A mic beside Send in the canvas composer and the Scapi panel.
  Whisper transcribes on the Mac; audio is never saved or sent. English and Hindi, with
  experimental Malayalam. The first use offers a one-time speech model download.
- **Draft routing (opt-in).** Settings → AI can suggest Ask/Edit, scope, object types and a
  model tier from the draft. Experimental TypeSafe Jev enhancement uses a separate key and
  falls back locally after 800 ms. Both switches default off. Confirmed command chips and a
  separate, undoable Deepen pass.
- **ChatGPT plan connection (local developer preview).** `pnpm dev` at 127.0.0.1 offers
  Continue with ChatGPT using OpenAI's open-source token-sharing flow. The hosted app and the
  macOS app do not offer ChatGPT sign-in yet; they show that it is unavailable and keep the
  Anthropic API key path. Billing connections never switch automatically.

Infrastructure: the BYOK Worker adds a TypeSafe Jev proxy route with its own rate budget. The
macOS CSP allows `https://api.typesafe.ai`. New restricted Tauri commands store the TypeSafe key
in Keychain. No database migration. macOS artifacts remain ad-hoc signed, without notarization.

Outstanding: live ChatGPT sign-in/inference and real-microphone acceptance have not been
exercised by a person on this release; Jev accuracy evaluation against the live service is
pending, which is why it stays experimental and off by default.
