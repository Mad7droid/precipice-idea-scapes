# Release 0.1.6 — 11 October 2026

Scapi gains its mascot: above the home title, in an empty Scapi chat, as a live mascot at the
end of the chat while Scapi works, and as small avatars on the Scapi header button, panel
header and canvas answers. MCP flow previews fit their map to a responsive viewport, offer an
**Expand preview** fullscreen request, and keep preview metadata in tool results.

## Deployed targets

| Target | Location | Status |
| --- | --- | --- |
| Web app and read-only viewer | https://precipice.pages.dev | 0.1.6 deployed by the `main` workflow |
| Hosted connector | https://precipice-mcp.precipice.workers.dev/mcp | Updated MCP Apps resource deployed by the same workflow |
| Publication API | Existing configured Worker | Unchanged service; redeployed by the workflow |
| Mac app | `/Applications/Precipice.app` | 0.1.6 built, installed, signature verified, local MCP handshake checked |

Production uses the existing D1, R2, OAuth KV, relay Durable Object, and configured secrets.
No database migration, new service, billing upgrade, client registration change or new
runtime dependency is required. The mascot is one bundled WebP and a local Canvas 2D
controller; it makes no network requests.

## Completed verification

- `pnpm verify`: Worker types, release version, production build, 57 test files and 727 tests,
  including the Scapi mascot lifecycle and the flow preview expand/viewport checks.
- `pnpm test:mcp`: six legacy bridge transport tests.
- Rust tests: five passed; the disposable Keychain credential test was intentionally not run.
- macOS production build and installation; ad-hoc bundle signature verified.
- Apple Silicon DMG packaged for the
  [GitHub release](https://github.com/Mad7droid/precipice-idea-scapes/releases/tag/v0.1.6);
  it is ad-hoc signed, not Developer ID signed or notarized. The download includes a SHA-256
  checksum.
- Installed `--mcp` handshake, tool discovery (including `preview_flow`) and the MCP Apps
  resource listing.
- Mascot placements checked in headless Chromium on desktop and narrow layouts, light and dark,
  with reduced motion; no console errors.
- The deployment workflow runs version validation and `scripts/smoke-release.mjs` after
  publishing Pages.

## Client acceptance still outstanding

- Live mascot reactions (thinking, success, failure) with a real Scapi request; the lifecycle
  is covered by unit tests.
- Mascot rendering inside the Tauri WebView window.
- **Expand preview** in real Claude and ChatGPT hosts. Hosts that decline fullscreen show a
  pointer to their own expand control.
- The client acceptance steps from [release 0.1.5](0.1.5.md) remain outstanding.
