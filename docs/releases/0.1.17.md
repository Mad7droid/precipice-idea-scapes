# Precipice 0.1.17

## Workspace

- Settings → General adds Current, Graphite and Field interface styles, independent of
  Light/Dark/System. Current stays the default; the logo, orange Scapi artwork and fonts are
  unchanged.
- Home leads with Continue working. Optional Active/Parked/Done states filter the library
  without changing edit time.
- Capture a note (Cmd/Ctrl+Alt+N) into a local Inbox, then edit, archive, delete archived notes,
  or add it to a new or closed scape in one transaction. Unsaved captures survive closing the
  dialog for the current tab.
- Local content search (Cmd/Ctrl+Shift+F) with excerpts, ↑/↓/Enter and focus on the matched
  object. No model or network request.
- Editor panel layout and selection restore per scape; Scapi task starters prepare drafts only.

## Data and compatibility

- Library backups include Inbox notes. Scapes and Inbox notes each have a 1,000 limit, so a
  file may hold up to 2,000 entries; builds before 0.1.17 reject files above 1,000 entries.
- Deleting a scape removes its work state, last-opened time and stored editor session.
- No database version, credential storage, native permission, publishing or agent-scope change.
  The inline pre-paint script changed, so the CSP hashes in `public/_headers` were updated.
- Rust `tauri-plugin-deep-link` now matches the JavaScript package (2.6.2).

## Verification

## Known verification limits

Native sign-in, dictation, cloud publication and quit/reopen were not manually exercised in the
packaged app before release. Local builds remain ad-hoc signed, so the first launch after
installing asks for Keychain access once.
