# Precipice 0.1.18

## Interface

- Light-mode selected navigation and Inbox view tabs drop the left accent stroke. A hairline
  accent outline follows the item's rounded corners instead, in Current, Graphite and Field.
  Dark mode is unchanged.

## Documentation

- 0.1.17 release status recorded in `docs/releases/0.1.17.md`.
- Design language updated: no side bars or edge strokes on selected items.

## Compatibility

CSS-only interface change. No data, permission, credential, publishing or CSP change.

## Verification

`pnpm verify`, `pnpm test:mcp` and `cargo test --locked` run before release; see the PR.

## Known verification limits

The outline was not visually checked in a browser by the agent before release.
