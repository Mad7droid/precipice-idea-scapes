## Remaining, accepted

- `glib` 0.18 (medium): pulled by Tauri's Linux GTK stack only; not compiled into the macOS app.
  Resolves when Tauri moves to a newer gtk-rs.
- `rsa` 0.9 (RUSTSEC-2023-0071, Marvin timing): introduced by jsonwebtoken's `rust_crypto`
  backend. Production only verifies RS256 signatures with public keys; the advisory concerns
  private-key operations. The `aws_lc_rs` backend avoids it but needs CMake in the build
  environment; revisit when CMake is part of the desktop toolchain.

## Verification

`pnpm verify` (980 tests), `pnpm test:mcp` (7), `cargo test` (49 passed, 3 ignored), and
`pnpm audit` reports no known vulnerabilities.
