# Release 0.1.9 — 11 October 2026

Scapi stays beneath the latest chat answer, returning to occasional random smiles, winks and
glances after work and the brief completion reaction. Click reactions remain available while
idle. Automatic reactions stop during work and pause offscreen, while the document is hidden,
and under reduced motion. Idle reactions do not show warning faces or success confetti.

The header's Ask Scapi control is an avatar-only icon button, retaining its tooltip,
accessible name and pressed state. Ask/Edit action buttons replace the send arrow with a
static Scapi avatar on a cream disc for contrast against the orange fill in either theme.
The Ask/Edit switcher and Stop action retain their existing behavior.

The changes are shared by web and macOS. No new dependency, infrastructure or database
migration is required. macOS artifacts remain ad-hoc signed, without notarization.

Visual checks use a fictional completed conversation on an isolated local origin. Tests cover
idle scheduling, interruption by real work, offscreen and hidden-document pausing, and reduced
motion. The production build passes.
