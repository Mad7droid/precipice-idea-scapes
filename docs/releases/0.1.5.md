# Release 0.1.5 — 10 October 2026

The hosted app and MCP connector include in-chat flow previews, explicit creation and discard,
shareable hosted snapshots with iframe code and withdrawal, the sidebar library workflow,
updated templates, and all-block editing in every template. Preview browsing and confirmation
make no additional model calls. Maintained repository guides cover these changes.

## Deployed targets

| Target | Location | Status |
| --- | --- | --- |
| Web app and read-only viewer | https://precipice.pages.dev | 0.1.5 deployed; current bundle and live configuration checked |
| Hosted connector | https://precipice-mcp.precipice.workers.dev/mcp | Updated MCP Apps resource and tools deployed |
| Publication API | Existing configured Worker | Unchanged service; current migration set and secrets verified |
| Mac app | `/Applications/Precipice.app` | 0.1.5 built, installed, signature verified, and local MCP round trip checked |

Production uses the existing D1, R2, OAuth KV, relay Durable Object, and configured secrets.
No database migration, new service, billing upgrade, or client registration change is required.
Mac packaging now sets `signingIdentity = "-"` so the whole bundle is sealed, and installation
and CI verify the seal before accepting the artifact.
Deployment-specific resource identifiers and credentials stay outside Git. `.env.production.local`
holds public build values locally and is ignored. The build version is consistent across
package.json, Cargo.toml, and the Tauri configuration.

## Completed verification

- `pnpm verify`: Worker types, release version, production build, 56 test files and 720 tests.
- `pnpm test:mcp`: six legacy bridge transport tests.
- Rust tests: five passed; the disposable Keychain credential test was intentionally not run.
- macOS production build and installation; explicit ad-hoc bundle signing and signature verification.
- Apple Silicon DMG packaged for the [GitHub release](https://github.com/Mad7droid/precipice-idea-scapes/releases/tag/v0.1.5);
  it is ad-hoc signed, not Developer ID signed or notarized. The download includes a SHA-256 checksum.
- Installed `--mcp` handshake, tool discovery, MCP Apps resource loading, a fictional one-block
  preview, UI-only metadata, and discard. No saved scape was created for that check.
- `pnpm smoke:release`: live editor bundle and endpoint configuration, relay CSP, `/p/*` and
  `/embed/*` viewer rewrites and framing policies, a fictional missing snapshot returning 404,
  MCP authentication challenge, advertised protected-resource metadata, OAuth issuer, and PKCE.
- Production connector secrets and publication migrations checked; no migrations pending.

The deployment workflow runs version validation and the same read-only smoke script after
publishing Pages. Run `pnpm smoke:release` locally after `pnpm build`, with production public
values in ignored `.env.production.local`. CI supplies those values as environment variables
and invokes `node scripts/smoke-release.mjs`.

## Client acceptance still outstanding

Real Claude and ChatGPT widget rendering, hosted-account consent, and a signed-out public
snapshot share/withdraw round trip have not been exercised in this release session. The native
computer-use connection failed at startup. Unit, transport, and route checks are evidence for
the implementation and deployment, not proof of those client-specific experiences.

Acceptance steps with fictional content:

1. Open the library’s **Agents** page; connect the desired client and choose the browser or
   desktop library. Keep that library host open. Refresh tool discovery if needed.
2. Ask for a signup flow using `preview_flow`. Inspect notes, journeys, and screens.
3. Choose **Create in Precipice**, then verify the saved flow and one-step undo. Test discard,
   expiry, and a stale existing-scape preview.
4. Share a fictional draft using **Make preview public**, open it signed out, and embed the
   `/embed/*` URL from another origin. Withdraw it and verify public reads are unavailable.
5. Refresh status after UI reload and confirm the saved creation/share outcome.

## Use and limits

See [MCP](../mcp.md) for chat setup, [library](../library.md) for navigation and templates,
[publishing](../publishing-runbook.md) for quotas and operations, and
[desktop](../desktop.md) for local installation and the ad-hoc signing boundary. Shared preview
links are unlisted and publicly readable. Unsaved chat previews are managed from chat or the
authenticated publication API, rather than the saved-scape Published page.
