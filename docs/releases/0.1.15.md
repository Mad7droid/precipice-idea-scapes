# Precipice 0.1.15

## Desktop AI connections

- Settings → AI now has an explicit selector for ChatGPT plan, Claude plan through Claude
  Code, and the separately billed Anthropic API connection.
- ChatGPT sign-in runs natively, opens the system browser, validates identity and plan
  permission, and keeps tokens in Keychain. Saved accounts, refresh, cancellation and
  disconnect are supported. Hosted ChatGPT sign-in is still unavailable.
- Claude plan uses a locally installed and signed-in Claude Code (tested version 2.1.283).
  It cannot run shell, filesystem or MCP tools. Scapi validates its proposals and applies
  them through the existing action/undo pipeline. Web search is unavailable for this path.
- Typed and live voice Ask/Edit/Connect/Deepen share these connections. A failure never
  switches to API billing automatically.

## Verification

- 842 web regression tests passed, plus the seven settings tests after a final disconnected
  model-label fix. Build, TypeScript, Worker and release version checks passed.
- Six MCP bridge tests and 27 standard native tests passed.
- Disposable Keychain round-trip passed. Synthetic speech through the real local Whisper
  recognizer returned “Add a note that says hello world.”
- Packaged Preview built, passed its signature check and detected the real Claude account.
  Keyboard selection, persisted provider choice and native ChatGPT browser launch were checked.

## Known verification limits

The owner deferred ChatGPT account authorization and then elected to ship the implementation.
A completed real ChatGPT inference, renewal and reconnect are therefore still unverified.
The live Claude request reached the provider but hit the owner's session usage limit;
a successful real Claude answer/edit remains unverified. Automated tool-loop tests use
simulated provider replies with the real canvas reducer, scope enforcement and undo.

Real microphone interaction and fresh-install speech-model downloads have not been certified.
The local Mac has its model installed; the repository has no configured
`PRECIPICE_MODELS_URL` GitHub variable. Existing desktop builds use ad-hoc signing and are
not notarized. The prior installed app's local data is preserved by retaining the bundle ID.

See [desktop AI connections](../desktop-ai-connections.md) for architecture and remaining checks.
