# Precipice 0.1.16

## AI connections and Keychain

- The Mac app defaults to the Claude plan. ChatGPT plan and the Anthropic API key remain
  explicit choices; the API key is never selected automatically.
- Settings → AI reads Connection → Model → Routing suggestions → Instructions. Only the
  selected connection shows its controls, and each connection remembers its own model.
- Desktop secrets share one Keychain item per app identity, read at most once per launch and
  only when needed. Jev no longer reads Keychain per request, unused connections are never
  checked, and a refused prompt waits for **Allow access**. The installed app moves earlier
  per-secret items into the new item once; preview identities start empty.
- Desktop keys save straight to Keychain; the session-only mode is removed.

## Verification

- `pnpm verify`: build, TypeScript, Worker and version checks, and 846 web tests passed.
- 27 standard native tests and six MCP bridge tests passed. The opt-in Keychain round-trip
  and vault cache tests passed against the local login Keychain.
- Settings → AI layout checked in the web development build.

## Known verification limits

Migration of an installed 0.1.15 app's saved credentials and the packaged Settings layout
have not been checked by the owner yet. Local builds remain ad-hoc signed, so the first
launch after each new build still asks for Keychain access once.
