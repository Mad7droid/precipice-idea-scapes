# Screenshot provenance

Product images must use fictional content in an isolated, signed-out browser library.
Do not capture the personal desktop library, real account details, keys, OAuth callbacks,
pairing codes, client credentials, or real unlisted publication addresses.

Create a fresh browser origin/profile, import a fictional fixture, and frame only the relevant
product surface. Inspect each image visually and with OCR before committing. Keep temporary
captures under `.context/`; only reviewed product images belong in this directory. Secret
pattern scanning does not identify all confidential prose or unlisted links.

Existing screenshots illustrate individual product features and may show earlier layouts.
The README identifies the older home screenshot; current navigation and behavior are documented
in [the library guide](../library.md). A screenshot is not evidence of production deployment.
